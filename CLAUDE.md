# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Personal portfolio website with a retro terminal/cyberpunk aesthetic. Static site deployed on Vercel from this repo — no package manager, no frameworks; a stdlib-only Python build.

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES6+)
- HTML5 Canvas (Snake game)
- Inter + Fira Code, self-hosted in `fonts/` for index.html and snake.html (about.html still loads Fira Code from Google Fonts)
- No dependencies; the only build step is the stdlib Python generator (`design-ref/build_html.py` + `stage.py`)

## Development

To develop locally, serve the files with any static file server:

```
python3 -m http.server 8000
```

The site is plain static HTML/CSS/JS. `index.html` is generated by `python3 design-ref/build_html.py`, locally or on Vercel.

### Update pipeline

1. Edit `content/experience.csv`, `content/projects.csv` or the copy in `design-ref/content.py` (the GitHub web editor works too).
2. Push to `master`. Vercel's Git integration runs the `buildCommand` in `vercel.json`: `build_html.py` (its asserts are the checks; a failed assert fails the deploy and the live site stays as it was), then `design-ref/stage.py`, which copies the pages and only the local files they reference into `public/`, the output directory. Other branches and PRs get preview deployments.
3. Locally: `python3 design-ref/build_html.py && python3 design-ref/stage.py && python3 -m http.server -d public 8000` previews exactly what ships.

Vercel's build image has Python 3.12; keep the scripts stdlib-only and 3.12-compatible (`uv run --python 3.12 --no-project python design-ref/build_html.py` checks it).

## Architecture

Each page is a self-contained HTML file with inline `<style>` and `<script>` blocks (no external CSS/JS files):

- **index.html** — **Generated, don't hand-edit.** Dark editorial portfolio (see `DESIGN.md`): hero → Work → Experience → About → Contact, vanilla CSS on a 4-column hairline grid that collapses to one column below 1024px. Animations use GSAP 3.15.0 (core, ScrollTrigger, SplitText, ScrambleText) plus Lenis 1.3.27 smooth scroll, vendored in `js/`; the page is fully visible without JS or with reduced motion. Regenerate with `python3 design-ref/build_html.py` after editing `content/experience.csv`, `content/projects.csv` (its `image` column points at card covers in `img/projects/`) or the copy in `design-ref/content.py`; the script asserts the featured/hidden projects before writing.
- **about.html** — Profile page with green-on-black terminal aesthetic, CRT scanline overlay, CTF-style decrypt animation, and traceroute simulation.
- **snake.html** — Hand-written, standalone canvas Snake game in the index.html theme (same tokens, fonts and hairline grid; halftone board, `--pop` food). Arrow keys/WASD, Space to start or pause, swipe and a d-pad on touch.

### Style notes

- `index.html` uses Inter + Fira Code with the `#141414` / `#F2F2F2` palette from `DESIGN.md`; `snake.html` copies those tokens by hand; `about.html` still uses its own vanilla green-on-black CRT style.
- Each page defines its own styles; there are no shared stylesheets.
- `design-ref/` holds the FigCraft build scripts (`build_portfolio.py`, `build_mobile.py`, via `fc.py`) and the HTML generator; `content.py` is the shared, I/O-free copy and sheet loader.
